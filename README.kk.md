# «Экзаменатор» қолданбасының сұрақтар банктері

> **Мәртебесі: бұл Әл-Фараби атындағы ҚазҰУ сұрақтар банктерінің бейресми репозиторийі, әрі ол әлі толық дайын емес.** Университет оны жарияламаған және тексермеген, сұрақтар емтиханның ресми тапсырмалары емес. Қазір мұнда бір университет, бір факультет, бір мамандық және бір семестр бар. Банктер әлі толықтырылып, жетілдіріліп жатыр, жауап кілттерін оқытушы тексермеген, қазақша және ағылшынша аудармалар машиналық. Қалталар құрылымы мен мазмұны өзгеруі мүмкін.

Бұл «Экзаменатор» қолданбасына арналған деректер репозиторийі: бөлімдер ағашы (университет, факультет, дәреже, мамандық, курс, оқу жылы, семестр, пән) және `exambank/2` форматындағы тест сұрақтарының банктері. Мұнда код жоқ. Қолданба, формат схемасы және пәрмен жолы `exam-platform` код репозиторийінде жатыр. Төмендегі мысалдарда ол осы қалтаның жанында тұр деп есептеледі (`../exam-platform`).

## Ішінде не бар

Қазір репозиторийде 7 банк және 2450 сұрақ бар: Әл-Фараби атындағы ҚазҰУ, Ақпараттық технологиялар және жасанды интеллект факультеті, бакалавриат, «Ақпараттық қауіпсіздік жүйелері» мамандығы, 1-курс, 2026 жыл, 1-семестр.

| Пән | Банк идентификаторы | Банк тілі | Сұрақтар |
| --- | --- | --- | --- |
| Психология | `kaznu/psychology` | ru | 350 |
| Саясаттану | `kaznu/political-science` | ru | 350 |
| Мәдениеттану | `kaznu/cultural-studies` | ru | 350 |
| Қазақстан тарихы | `kaznu/history-of-kazakhstan` | ru | 350 |
| Қазақ тілі, A1 | `kaznu/kazakh-a1` | ru | 350 |
| Қазақ тілі, A2 | `kaznu/kazakh-a2` | ru | 350 |
| Қазақ тілі, B1–B2 | `kaznu/kazakh-b1-b2` | kk | 350 |

Қазақ тілінің үш банкі «Қазақ тілі» пән-тобында тұр, әр деңгейге бір банктен.

Сұрақтар авторлық және оқу мақсатындағы, емтиханның ресми тапсырмалары емес. Тұжырымдар, нұсқалар саны және төрт күрделілік деңгейіне бөлу қорытынды тесттің форматын қайталайды. Жауап кілттері дәрістер, оқулықтар және ашық дереккөздер бойынша жасалған, оларды оқытушы тексермеген. Психология, саясаттану және мәдениеттану банктерінің қазақша және ағылшынша аудармасы бар. Аударма машиналық және тексеруден өтпеген. Қалған банктер тек банктің өз тілінде беріледі. Енгізу режиміндегі автотексеру сұрақтардың бір бөлігінде ғана бар: психологияда 18 сұрақ, тарих пен қазақ тілінде шамамен әр бесінші сұрақ, ал саясаттану мен мәдениеттануда мүлде жоқ. Қалған сұрақтарды енгізу режимінде студент өзі тексереді.

## Құрылым

```
catalog.json                  ағаш түйіндерінің түрлері, семестрдегі «орын» белгісі
kaznu/                        университет (node.json)
  fit-ai/                     факультет
    bachelor/                 дәреже
      information-security-systems/   мамандық
        course-1/             курс
          2026/               оқу жылы: 1-курс 2025 жылға да болуы мүмкін
            semester-1/       семестр (items тізімі бар node.json)
              psychology/     банк: bank.json, questions/t01.json …, translations/<локаль>/
              political-science/
              cultural-studies/
              history-of-kazakhstan/
              kazakh-language/  пән-топ (node.json)
                a1/  a2/  b1-b2/   деңгей банктері
schema/                       форматтың JSON Schema файлы, автоматты түрде жасалады
source/v1/                    ескі форматтағы бастапқы банктер (1.0 нұсқасы)
```

`node.json` бар қалта ағаштың түйіні болады, ал `bank.json` бар қалта өз түйінінің ішіндегі банк болады. Түйін идентификаторы қалтаның түбірден бастап жолымен бірдей, ал банк идентификаторы `bank.json` файлынан алынады және жолға тәуелді емес. Түйін ішіндегі көрсету ретін оның `node.json` файлындағы `items` тізімі белгілейді. `schema` және `source` қалталары ағашқа кірмейді. Форматтың толық сипаттамасы код репозиторийіндегі `docs/FORMAT.md` файлында.

## Қалай тексеру керек

Код репозиторийінде тәуелділіктерді бір рет орнатыңыз (`npm install`), содан кейін осы қалтадан мынаны іске қосыңыз:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts validate .
```

Сәтті аяқталса, пәрмен `OK: 7 banks, 2450 questions` деп шығарады. Қателер болса, оларды тізіп шығады да, 1 кодымен аяқталады. Ол қалталардың орналасуын, схемаларды, идентификаторлардың қайталануын, кілттерді және еркін енгізу блоктарын тексереді. Оны әр коммит алдында іске қосыңыз.

## Қалай қосу керек

Бар семестрге жаңа банк қосу:

1. Банк қалтасын семестр қалтасының ішінде жасаңыз, мысалы, `kaznu/fit-ai/bachelor/information-security-systems/course-1/2026/semester-1/<пән>/`.
2. Оған `kaznu/<пән>` түріндегі (кіші латын әріптері, цифрлар, дефис) жаңа идентификаторы бар `bank.json` файлын және `questions/` ішіне сұрақ файлдарын салыңыз. Идентификатор бүкіл репозиторийде бірегей болуы тиіс және жарияланған соң өзгермейді.
3. Қалта атауын семестрдің `node.json` файлындағы `items` тізіміне қосыңыз. Әйтпесе банк тізімделгендердің соңында тұрады.
4. `validate` іске қосыңыз.

Ескі форматтағы банкті алдымен `migrate` пәрменімен ауыстыруға болады:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts migrate <v1.json> <банк-id> <банк-қалтасы>
```

Пән-топ: `subject` түріндегі `node.json` бар қалта жасаңыз, оның ішіне деңгей банктерінің қалталарын салып, оларды `items` ішіне тізіңіз.

Жаңа семестр, курс, оқу жылы (мысалы, `course-1/2026` қасына `course-1/2025`) немесе басқа деңгей: қажетті түрдегі `node.json` бар қалта жасаңыз (`semester`, `course`, `academic-year` және т.б., түрлері `catalog.json` ішінде сипатталған) да, ішіне банктерді немесе кірістірілген түйіндерді салыңыз. Жаңа түрді алдымен `catalog.json` файлына қосыңыз.

Аудармаларды `<банк>/translations/<локаль>/` ішіне бөлек файлдармен салыңыз да, мына пәрменмен қосыңыз:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts merge-translations .
```

## Қалай құрастыру керек

`compile` пәрмені ағашты аттарында хэш бар файлдарға (`index.json`, `nodes/`, `banks/`) айналдырады, оларды қолданба оқиды:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts compile . ../site
```

Нәтиже жазылатын қалта құрастыру алдында өшіріледі, сондықтан ол осы қалтаның сыртында тұруы тиіс және оны қамтымауы керек.

## Қолданбаға қалай қосу керек

Күрделілігінің өсу ретімен үш тәсіл:

- Осы репозиторийді код репозиторийінің жанына `exam-content` атымен қойыңыз. Интерфейсті құрастыру (`npm --prefix apps/ui run build`) оны өзі алып, қолданбаға көшірме ретінде кірістіреді.
- Интерфейсті құрастыру кезінде қалтаны `EXAM_CONTENT_DIR` айнымалысы арқылы тікелей көрсетіңіз.
- Құрастырылған сайтты жариялаңыз, мысалы, GitHub Pages-те, және оның мекенжайын қолданбаны құрастыру кезінде `VITE_CONTENT_URLS` айнымалысында беріңіз (қолданба ішіндегі көшірме қажет болмаса, `EXAM_CONTENT_DIR=none` айнымалысымен бірге). Сонда банктер қолданбаны қайта құрастырмай жаңарады. Қадамдық нұсқаулық пен workflow үлгілері код репозиторийінің `docs/PUBLISHING.md` файлында.

Осы репозиторийдің құрастырылған сайты GitHub Pages арқылы `gh-pages` тармағынан жарияланады: https://sssox.github.io/exam-content. Бұл мекенжай код репозиторийінің `content-sources.json` файлында жазылған. Өз көшірмеңізді жарияласаңыз, өз мекенжайыңызды қойыңыз.
