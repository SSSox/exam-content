# Банки вопросов «Экзаменатора»

> **Статус: это неофициальный репозиторий банков КазНУ имени аль-Фараби, и он пока не готов до конца.** Университет его не выпускал и не проверял, вопросы не являются официальными заданиями экзамена. Сейчас здесь один университет, один факультет, одна специальность и один семестр. Банки ещё наполняются и дорабатываются, ключи преподаватель не вычитывал, переводы на казахский и английский машинные. Структура папок и содержимое могут меняться.

Это репозиторий данных для приложения «Экзаменатор»: дерево разделов (университет, факультет, степень, специальность, курс, учебный год, семестр, предмет) и банки тестовых вопросов в формате `exambank/2`. Кода здесь нет. Приложение, схема формата и командная строка лежат в репозитории кода `exam-platform`. В примерах ниже он стоит рядом с этой папкой (`../exam-platform`).

## Что внутри

Сейчас в репозитории 7 банков и 2450 вопросов: университет КазНУ имени аль-Фараби, факультет информационных технологий и искусственного интеллекта, бакалавриат, специальность «Системы информационной безопасности», 1 курс, 2026 год, 1 семестр.

| Предмет | Идентификатор банка | Язык банка | Вопросов |
| --- | --- | --- | --- |
| Психология | `kaznu/psychology` | ru | 350 |
| Политология | `kaznu/political-science` | ru | 350 |
| Культурология | `kaznu/cultural-studies` | ru | 350 |
| История Казахстана | `kaznu/history-of-kazakhstan` | ru | 350 |
| Казахский язык, A1 | `kaznu/kazakh-a1` | ru | 350 |
| Казахский язык, A2 | `kaznu/kazakh-a2` | ru | 350 |
| Казахский язык, B1–B2 | `kaznu/kazakh-b1-b2` | kk | 350 |

Три казахских банка лежат в предмет-группе «Казахский язык», по одному банку на уровень.

Вопросы авторские и учебные, официальными заданиями экзамена они не являются. Формулировки, число вариантов и распределение по четырём уровням сложности повторяют формат итогового теста. Ключи составлены по лекциям, учебникам и открытым источникам, преподаватель их не вычитывал. У психологии, политологии и культурологии есть перевод на казахский и английский. Перевод машинный и не вычитан. Остальные банки есть только на языке банка. Автопроверка в режиме ввода есть лишь у части вопросов: у психологии их 18, у истории и казахского языка примерно каждый пятый, у политологии и культурологии нет совсем. Остальные вопросы в режиме ввода студент проверяет сам.

## Структура

```
catalog.json                  виды узлов дерева, отметка «место» у семестра
kaznu/                        университет (node.json)
  fit-ai/                     факультет
    bachelor/                 степень
      information-security-systems/   специальность
        course-1/             курс
          2026/               учебный год: курс 1 может быть и за 2025 год
            semester-1/       семестр (node.json со списком items)
              psychology/     банк: bank.json, questions/t01.json …, translations/<локаль>/
              political-science/
              cultural-studies/
              history-of-kazakhstan/
              kazakh-language/  предмет-группа (node.json)
                a1/  a2/  b1-b2/   банки-уровни
schema/                       JSON Schema формата, генерируется
source/v1/                    исходные банки старого формата (версия 1.0)
```

Если в папке лежит `node.json`, это узел дерева, а если `bank.json`, то банк внутри своего узла. Идентификатор узла совпадает с путём его папки от корня. Идентификатор банка берётся из `bank.json` и от пути не зависит. Порядок показа внутри узла задаёт список `items` в его `node.json`. Папки `schema` и `source` в дерево не входят. Полное описание формата лежит в `docs/FORMAT.md` в репозитории кода.

## Как проверить

Один раз установите зависимости в репозитории кода (`npm install`), затем из этой папки:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts validate .
```

При успехе команда печатает `OK: 7 banks, 2450 questions`. При ошибках она перечисляет их и завершается с кодом 1. Она проверяет раскладку папок, схемы, повторы идентификаторов, ключи и блоки свободного ввода. Запускайте её перед каждым коммитом.

## Как добавить

Новый банк в существующий семестр:

1. Создайте папку банка внутри папки семестра, например `kaznu/fit-ai/bachelor/information-security-systems/course-1/2026/semester-1/<предмет>/`.
2. Положите в неё `bank.json` с новым идентификатором вида `kaznu/<предмет>` (строчная латиница, цифры, дефис) и файлы вопросов в `questions/`. Идентификатор должен быть уникален во всём репозитории и после публикации не меняется.
3. Добавьте имя папки в `items` файла `node.json` семестра. Иначе банк встанет после перечисленных.
4. Запустите `validate`.

Банк в старом формате можно сначала перевести командой `migrate`:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts migrate <v1.json> <id-банка> <папка-банка>
```

Предмет-группа: создайте папку с `node.json` вида `subject`, положите в неё папки банков-уровней и перечислите их в `items`.

Новый семестр, курс, учебный год (например, `course-1/2025` рядом с `course-1/2026`) или другой уровень: создайте папку с `node.json` нужного вида (`semester`, `course`, `academic-year` и так далее, виды описаны в `catalog.json`) и положите внутрь банки или вложенные узлы. Новый вид сначала добавьте в `catalog.json`.

Переводы кладите в `<банк>/translations/<локаль>/` отдельными файлами, затем вливайте их командой:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts merge-translations .
```

## Как собрать

Команда `compile` превращает дерево в файлы с хэшами в именах (`index.json`, `nodes/`, `banks/`), которые читает приложение:

```bash
node ../exam-platform/packages/content-tools/src/cli.ts compile . ../site
```

Перед сборкой команда стирает папку назначения, поэтому папка назначения должна лежать вне этой папки и не содержать её.

## Как подключить к приложению

Три способа, по возрастанию усилий:

- Положите этот репозиторий рядом с репозиторием кода под именем `exam-content`. Сборка интерфейса (`npm --prefix apps/ui run build`) возьмёт его сама и встроит в приложение как снимок.
- Укажите папку явно через переменную `EXAM_CONTENT_DIR` при сборке интерфейса.
- Опубликуйте собранный сайт, например на GitHub Pages, и передайте его адрес при сборке приложения в переменной `VITE_CONTENT_URLS` (вместе с `EXAM_CONTENT_DIR=none`, если снимок внутри приложения не нужен). Тогда банки обновляются без пересборки приложения. Пошаговая инструкция и шаблоны workflow лежат в `docs/PUBLISHING.md` репозитория кода.

Собранный сайт этого репозитория публикуется на GitHub Pages из ветки `gh-pages`: https://sssox.github.io/exam-content. Этот адрес записан в `content-sources.json` репозитория кода. Если вы публикуете свою копию, подставьте свой адрес.
